# Описание

Новый человек создаёт репозиторий команды из шаблона, ставит `kb-search` и `kb-maintain`, задаёт вопросы в чате. Шаги постановки — файл `GETTING-STARTED.md` в корне репозитория. Правда — в git после merge в репозиторий команды. Витрину (Confluence и т.п.) обновляют отдельно.

Владелец процесса — команда [Дельта](../teams/delta.md).
