# raw/

Сюда кладут заметки, итоги встреч, черновики. Снимки трекера — не сюда, это `kb-snapshot` и сразу wiki.

1. Файл в `raw/` или в одной подпапке (`raw/ivanova/note.md`). Глубже не надо.
2. Ветку `kb/<DD-MM-YYYY>/<суть>` создаёте вы.
3. В чат: `/kb-maintain` и «внеси в базу …».
4. Wiki сами не оформляйте — это сделает агент после «ок».

```yaml
---
type: manual-source
title: <название>
version: 1
updated: 20-09-2026
updated_by: <ФИО>
---
```
