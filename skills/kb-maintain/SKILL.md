# Ведение базы знаний

Правила — `AGENTS.md`. Только ingest из raw и правка страницы.

Порядок: diff → план в чат → правки в дереве → «ок» → `status: current` → **один** коммит → PR. До «ок» не коммитить и не пушить. Amend нельзя.

Основная ветка — `main`.

## Кто создаёт ветку

- **Ingest** — человек. Агент не pull и не создаёт ветку. Проверить: не `main`, имя `kb/<DD-MM-YYYY>/…`.
- **Update** — агент: `git pull origin main` → `git checkout -b kb/<DD-MM-YYYY>/update-<слаг>`.

После PR: ссылка, список файлов, просьба смержить. Merge — человек. Витрину агент не публикует.

## Операция 1. Ingest

**Предусловие:** ветка человека и файл в `knowledge-base/raw/` или в одной подпапке (`raw/ivanova/note.md`). Глубже не искать.

1. `git status` и `git diff` по указанному raw. Читать **содержание**, не имя файла.
2. План в чат. Wiki ещё не трогать. Неясно куда — спросить, страницы не создавать.
3. Создать или обновить страницы (не плодить дубли).
4. Шапка: `type` обязателен; `status: review`; `sources` — полный путь raw; `updated` = сегодня `DD-MM-YYYY`.
5. Обновить `wiki/…/index.md`. Корневой `knowledge-base/index.md` — только разделы; листья туда не писать. Новый каталог — только если человек явно просит.
6. Запись в `knowledge-base/log.md`: `## [DD-MM-YYYY] ingest | <описание>`.
7. Не коммитить. Список в чат: wiki **и** путь raw. «Согласуй: ок / правки».
8. «правки» — править дерево, снова список. Коммита нет.
9. После «ок»: на затронутых wiki-страницах (не index/log) `status: current`. Проверить, что не осталось `review`. Затем **один** коммит: wiki + `log.md` + файл raw. `git push` → создать PR в `main` штатным способом команды (gh / GitLab / кнопка). Ссылка в чат.

## Операция 2. Update

Ветку создаёт агент (см. выше).

1. Открыть страницу, внести правки, обновить `updated` и связи.
2. `log.md`: `## [DD-MM-YYYY] update | <страница> — <что>`.
3. Список → «ок / правки». Коммита нет.
4. После «ок»: `current`, один коммит, push, PR, ссылка. Merge — человек.

## Шаблон страницы

```markdown
---
type: <Тип>
title: <Имя>
description: <Одно предложение>
owner: <Команда>
status: review
tags: [тег]
sources: [raw/<путь>.md]
updated: <DD-MM-YYYY>
---

# Описание
...

# Источники
[1] ...
```

## Не этот скилл

`kb-search`, `kb-snapshot`, `kb-index`.
