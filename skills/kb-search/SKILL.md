# Поиск по базе знаний

Правила — `knowledge-base/AGENTS.md`. Только отвечает: в базу не писать. `raw/` и `log.md` не читать как правду. Wiki и raw разошлись — верить wiki. В wiki нет — «в базе этого нет», без фактов из общих знаний модели.

Основная ветка — `main`.

## Формат ответа

Человек должен открыть ссылку. Если репозиторий уже в сети — markdown-ссылка, не голый путь. Если клон только локальный — путь файла, `owner` и `status` из шапки.

```markdown
**Ответ:** Команда Дельта отвечает за внутренние сервисы. PO — Анна Петрова.

**Источник (wiki):** [Дельта](knowledge-base/wiki/teams/delta.md) · владелец: Дельта · статус: current
```

- Каждый источник с новой строки.
- Нет источника — ответ неготовый.
- Если `status` не `current` — после источников строка, что страница ещё не согласована.
- Карточки индекса человеку не давать как «источник правды»: дать `url` из карточки (внешний документ).

## Шаги

0. **Правда = `origin/main`**, не feature и не грязное дерево.
   - `git fetch origin main`.
   - Первое обращение в диалоге — fetch обязателен. Повторно — если прошло >30 мин, пользователь просит обновить, или только что влили PR.
   - Не `git checkout main`, если текущая ветка другая.
   - Читать: `git show origin/main:knowledge-base/<путь>` или Read, если уже на `main` и `git status` чистый после ff-only с origin.
   - Fetch не удался, но ref есть — читать его и предупредить. Нет ref — стоп.

1. Каталог — `knowledge-base/index.md` с `origin/main`. Не сканировать всю БЗ и не грепать `raw/`.

2. Маршрут:
   - кто / процесс / термин / как устроено у нас → `wiki/`
   - где лежит документ / спека / инструкция на портале → `indexes/`, затем тело **в источнике** (клон или URL), не копия в wiki
   - неясно — wiki + индекс

3. По маршруту wiki: из каталога открыть `wiki/<раздел>/index.md`, из него — страницу. Не останавливаться на корневом `index.md`: там только разделы. Дальше 5–10 релевантных страниц (или карточек индекса). Тело внешней спеки — из клона/`url`, **не** копировать в wiki.

4. Ответ только по формату выше и только по прочитанным страницам. В wiki и индексе нет — одна фраза «в базе этого нет». Факты из общих знаний модели не добавлять. Не предлагать завести страницу, пока пользователь сам не попросит внести в БЗ.

## Не этот скилл

`kb-maintain`, `kb-snapshot`, `kb-index`.
