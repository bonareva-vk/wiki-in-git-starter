# Снимок живого реестра → wiki

Сначала работают поиск и ведение. Этот скилл — когда уже есть трекер или регулярный CSV.

Это шаблон, не готовый Jira-скилл. Пока человек не подставил источник — **стоп**, не выдумывать JQL и папку.

Пишет в `knowledge-base/wiki/<раздел>/` (папку человек создал и прописал в `AGENTS.md`, часто `wiki/registry/`). В `raw/` не пишет. `kb-maintain` не вызывает.

Источник статусов — трекер. В git — снимок после «ок».

## Перед первым вызовом (человек)

1. MCP трекера только чтение — или CSV/JSON вне `raw/`.
2. Папка wiki + та же папка в дереве `AGENTS.md`.
3. В шапке `AGENTS.md` этот скилл — «сейчас».
4. В чате зафиксировать: система, фильтр, поле-ключ, каталог wiki.

## Источник (подставьте один)

Выберите и не меняйте в середине прогона:

1. **Файл-экспорт** — CSV/JSON, который человек положил в чат или в рабочую папку вне `raw/`.
2. **MCP только чтение** — поиск ключей + чтение карточки. Write-инструменты трекера **не** вызывать.

Зафиксируйте в чате: система, фильтр (аналог JQL), каталог wiki, поле-идентификатор (ключ).

## Шаги

1. Предусловие: источник доступен; иначе стоп. В отчёт «До»: сколько страниц-ключей уже в целевом каталоге.
2. Ветка: `git pull origin main` → `git checkout -b kb/<DD-MM-YYYY>/snapshot-<суть>`.
3. **Полный список ключей до тел.** Выгрузить все идентификаторы, распечатать в чат (`total` + список). Не начинать карточки, пока список не полный. Не собирать ключи, читая тела постранично.
4. По списку прочитать карточку и **перезаписать** `wiki/<раздел>/<ключ>.md`. Коммита до «ок» нет.
5. Сверить файлы каталога со списком ключей. Нет файла — добрать, не переходить к удалениям.
6. Ключи, которых больше нет в источнике — удалить только их страницы. Чужие файлы каталога не трогать.
7. Обновить `index.md` раздела (строки ключей). `log.md`: `## [DD-MM-YYYY] snapshot | <система> → wiki/<раздел> — <N>`.
8. Отчёт → «Согласуй: ок / не сейчас». Коммита нет. «не сейчас» — стоп без push.
9. После «ок» — **один** коммит только файлов прогона → push → PR в `main`. **Merge — человек.**

Это не цикл «ок / правки» по формулировкам. Это добро на пакет снимка.

## Страница-ключ (минимум)

YAML: `type`, `title`, `status: current` после «ок», `sources: [<url карточки>]`, `updated`. Тело — таблица полей источника + описание. Не выкидывать поля, которых «нет в шаблоне»: добавить строку таблицы.

## Запрещено

- Писать в `raw/`.
- Несколько коммитов на один снимок.
- Менять исходный трекер.
- Смешивать с ingest из заметок (`kb-maintain`).
