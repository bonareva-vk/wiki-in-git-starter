# Указатели на документы у источника

Сначала поиск и ведение. Этот скилл — когда спеки или портал живут не в этой wiki.

Это шаблон указателя, не готовый индекс «нашего» Bitbucket/портала. Пока нет строки в `sources.md` и клона или MCP — **стоп**.

Карточки в `knowledge-base/indexes/`, тела не копировать. `kb-maintain` не вызывать.

## Перед первым вызовом (человек)

1. Строка в `knowledge-base/indexes/sources.md`.
2. Клон на диске **или** MCP источника (для git часто GitHub MCP). Агент не клонирует.
3. В шапке `knowledge-base/AGENTS.md` этот скилл — «сейчас».

## Когда

После **merge в основную ветку** источника из `knowledge-base/indexes/sources.md`. Пока изменения только в feature / открытом PR — **стоп**, запись не предлагать.

Пишет только `knowledge-base/indexes/` (+ `log.md`). Ветку БЗ создаёт агент **после «ок»**.

## Предусловие

1. Строка в `sources.md`: `id`, что за источник, ветка или корень, маска путей, где клон (если git).
2. Git-источник: локальный клон есть; агент **не** клонирует. Смотреть `origin/<ветка>`, не working tree.
3. Портал: только чтение API/MCP, если есть; иначе карточка из заголовка + URL, без выдуманного тела.

## Шаги

1. Если в вызове указан `id` — только эта строка; иначе все строки реестра.
2. Сверить **множество path / id** источника с записями в `indexes/entries/`:
   - есть в источнике, нет карточки → **add**;
   - карточка есть, в источнике нет → **remove**;
   - тот же path/id — **не** переписывать карточку, даже если текст снаружи изменился.
3. Отчёт в чат: сколько add/remove (без полного дампа тел). Не коммитить. «Согласуй: ок / не сейчас».
4. Совпало всё — «индекс актуален», вопрос про запись не задавать.
5. После «ок»: `git pull origin main` → ветка `kb/<DD-MM-YYYY>/index-<id>`.
6. Для **новых** path: краткое `# Описание` (1–3 предложения из начала документа, не тело целиком), поле `url`, `status: current`.
7. Один коммит → push → PR. В PR только `indexes/**` и при необходимости `log.md`. **Merge — человек.**

`log.md`: `## [DD-MM-YYYY] index-sync | <id> — add <n> · remove <n>`.

## Карточка

```markdown
---
type: index-entry
title: <имя файла или страницы>
source_id: <id из sources.md>
path: <путь в источнике>
url: <https://…>
owner: <команда>
status: current
updated: <DD-MM-YYYY>
---

# Описание
<1–3 предложения>

# Источник
[<path>](<url>)
```

## Запрещено

- Индексировать feature / рабочее дерево клона.
- Копировать тело в wiki.
- Переписывать карточку при правке текста того же path.
- Править `sources.md` без просьбы человека.
- Merge PR агентом.
